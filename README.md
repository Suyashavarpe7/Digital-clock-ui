## 🎯 Features

- Real‑time digital clock (HH:MM:SS)  
- 12‑hour / 24‑hour format toggle  
- Smooth transitions / blinking colons  
- 🌓 Dark mode / light mode  
- Optional custom fonts & colors  
- Responsive design — works on mobile, tablet, desktop.
